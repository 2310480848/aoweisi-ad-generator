# 分镜表叙事技法 · 真实使用型

对照 原版 原版分镜表重写：把规划转成景别、运镜、时长、动作、声音、信息释放和转场。

---

## 一、分镜表定位

本类型基础流程：拿起产品 -> 打开/取量 -> 涂抹/使用 -> 观察反馈 -> 放回/带走。每一镜必须有清楚职能，不能只做视觉填充。

## 二、单镜必答六件事

- 主体：谁/什么在画面中心，产品在画面哪个位置。
- 新信息：这一镜比上一镜新增什么。
- 景别理由：全景交代空间，中景交代动作，近景交代关系，特写证明细节。
- 运镜理由：固定读信息，缓推靠近证据，缓拉揭示整体，平移展示关系，跟拍保留使用路径。
- 动作轨迹：手、眼神、身体重心、产品位置如何变化。
- 转场钩子：上一镜如何接入，本镜如何交给下一镜。

## 三、景别策略

| 景别 | 使用条件 | 禁止 |
|---|---|---|
| 全景 | 建立空间、品牌秩序、场景职能 | 无信息空景 |
| 中景 | 完整使用动作、人物与产品关系 | 只当过渡填充 |
| 近景 | 手、脸、产品和反馈关系 | 无产品关联的人脸空镜 |
| 特写/微距 | 质地、包装、标签、肤感、证据 | 连续重复同一信息 |

## 四、运镜节奏

- 固定镜头：包装、标签、质地、表情需要被读清。
- 缓推：靠近卖点证据；速度越慢，越强调观察。
- 缓拉：从产品局部揭示人物/场景/结果。
- 横移：展示系列产品、台面关系或人物动线。
- 跟拍：保留真实使用路径。
- 突然静止：只用于发现、结果确认或品牌收束。

## 五、时长把控

| 时长 | 用法 |
|---|---|
| 0.8-1.5s | 快切质地、包装细节、动作节点 |
| 2-3s | 常规产品、人物、使用动作 |
| 3-4s | 完整动作链、前后对比、情绪变化 |
| 4-6s | 只有持续新增信息时允许，否则拆镜 |

## 六、动作与产品连续性

- 单镜动作不超过两个。
- 产品位置要连续：台面 -> 手中 -> 脸侧 -> 镜前/包中。
- 手部动作写清握法、方向、距离和接触点。
- 结果镜头必须连接到前面的使用或证据镜头。

## 七、声音与转场

- 产品声可以做转场钩子：开盖声切微距、按压声切质地、包装声切主视觉。
- 视线匹配：人物看向产品，下一镜切产品。
- 动作匹配：旋开盖子，下一镜切膏体/刷头。
- 位置匹配：产品在画面右侧，下一镜同位置出现，保持观看连续性。

## 八、禁止

跳过关键动作、手脸产品关系不清；无职能空镜、无信息长镜头、连续同类特写、景别和运镜无理由、旁白承担全部解释。
