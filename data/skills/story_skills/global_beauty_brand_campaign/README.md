# 品牌大片型 · 导演叙事手册

对照 原版 原版叙事手册重写：定义广告怎么拍、信息怎么释放、产品怎么进入，而不是只定义内容类型。

---

## 一、叙事定位

- 基础流程：品牌氛围 -> 主视觉产品 -> 人物/材质强化 -> 系列镜头 -> 高级收尾。
- 语气：克制、高级、仪式感。
- 每段都必须回答：观众现在知道什么、产品新增什么、下一镜为什么继续看。
- 产品不是贴片，必须成为动作、证据、情绪或结果的触发物。

## 二、信息释放

| 阶段 | 目标 | 镜头任务 |
|---|---|---|
| 开场 0-3s | 建立注意力 | 一个视觉钩子、痛点、质地或面孔 |
| 中段 | 释放证据 | 使用动作、材质、成分、肤感、场景反馈 |
| 后段 | 形成记忆 | 产品主视觉、结果、人群/场景扩展、品牌收束 |
| 结尾 | 明确下一步 | 包装、名称、卖点或购买锚点清楚 |

## 三、段落规划字段

- 段落目标：这一段让观众相信什么。
- 观众已知/未知：哪些信息已经给出，哪些暂时隐藏。
- 产品职能：触发物、证据物、解决方案、身份符号或情绪锚点。
- 场景职能：使用、展示、证明、转场或收束。
- 核心动作：拿起、打开、取量、涂抹、观察、放回、携带。
- 声音线索：开盖、按压、刷毛、包装、环境底噪或短旁白。

## 四、镜头执行原则

- 小信息用台词，大信息用画面。
- 每个卖点至少有一个视觉证据，不能只靠旁白。
- 每个镜头只承担一个核心信息，复杂信息拆镜。
- 情绪变化必须由动作、光源或产品触发。
- 转场优先动作匹配、视线匹配、产品位置匹配和声音桥。

## 五、分镜表检查

- 是否每镜都有主体、产品位置、新信息、景别理由、运镜理由、转场钩子。
- 是否存在连续同类特写；有则合并或改成动作/结果镜头。
- 是否有产品从台面到手中到脸侧/场景中的连续路径。
- 是否有至少一个可被静帧读懂的主视觉收束。

## 六、禁止

廉价硬广、无信息空镜、为高级而高级，无信息空镜、连续重复产品特写、旁白承担全部解释、产品到结尾才出现、人物动作和卖点无关。
