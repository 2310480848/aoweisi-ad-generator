# 导演规划叙事技法 · 科普解释型

对照 原版 原版导演规划重写：先确定信息操控、情绪曲线、场景职能、声音方向和产品证据，再交给分镜表执行。

---

## 一、主题与商业内核

- 本类型流程：问题提出 -> 原理解释 -> 成分/结构证据 -> 使用方法 -> 结论。
- 观众离场感：记住一个产品理由，而不是只记住漂亮画面。
- 产品角色：触发物、证据物、解决方案、身份符号、情绪锚点，规划时必须选定一种主职能。

## 二、信息操控

| 信息层 | 规划问题 |
|---|---|
| 观众已知 | 开场 3 秒内知道什么：产品/痛点/人物/情绪？ |
| 观众未知 | 暂时隐藏什么，留到中段或结尾揭示？ |
| 产品证据 | 哪些画面证明卖点：质地、成分、使用、结果、场景反馈？ |
| 转化锚点 | 结尾留哪个包装、名称、卖点或行动？ |

## 三、段落节奏

- 钩子：必须是画面钩子，少用口播开场。
- 递进：每段新增一种信息，不重复同一产品角度。
- 释放：看到使用或证据后，给 1 个反馈镜头。
- 收束：回到产品、人物状态或品牌主视觉。

## 四、场景职能

| 场景 | 职能 |
|---|---|
| 浴室/镜前 | 使用、观察肤感、真实动作 |
| 梳妆台/台面 | 产品结构、包装、质地证据 |
| 街头/通勤 | 持妆、便携、生活反馈 |
| 实验/白棚 | 成分、质地、科学可信度 |
| 精品/暗调空间 | 品牌感、质感、礼赠、收束 |

## 五、声音方向

- 产品声：开盖、按压、旋转、刷毛摩擦、包装纸声。
- 环境声：水声、街声、室内底噪、脚步、布料摩擦。
- 旁白：只补充画面无法表达的信息，不替代证据。
- 音乐：服务 清楚、理性、可验证，不能盖过产品动作声。

## 六、交付给分镜表的字段

段落目标、观众已知/未知、产品职能、场景职能、核心动作、证据镜头、声音线索、转场钩子、禁止项。

## 七、禁止

伪科学、复杂术语堆叠、讲解压倒画面，只写主题不写镜头、卖点无证据、情绪无触发、产品无动作、场景无职能。
