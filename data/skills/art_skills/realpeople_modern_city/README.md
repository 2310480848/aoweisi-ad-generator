# 真人都市现代美妆视觉 · 视觉手册

对照 原版 原版视觉手册重写：这不是风格口号，而是人物、产品、场景、光源、材质、镜头都能执行的生产规范。

---

## 一、风格定位

- 视觉核心：真实都市、电影摄影、可拍摄、当代生活质感。
- 色彩系统：真实肤色、城市灰、玻璃蓝、木色、通勤中性色。主色最多 2 个，辅助色最多 2 个；不要让每个镜头随机换调色。
- 光源系统：自然窗光、屏幕冷光、街灯、室内暖光，来源明确。每张图必须能说清主光来源、方向和软硬。
- 场景系统：写字楼、咖啡厅、浴室、公寓、街口、地铁、便利店。场景要承担使用、展示、证明或收束职能。
- 材质系统：真实皮肤、服装褶皱、玻璃反射、屏幕、包装、城市材质。材质必须可被摄影机验证，不写空泛高级词。

## 二、原版 式细颗粒规则

| 维度 | 必写 | 禁止 |
|---|---|---|
| 人物 | 年龄段、肤色、面部识别点、体态、眼神、手部动作 | 网红脸、塑料皮肤、无身份的人 |
| 产品 | 包装形状、标签朝向、比例、开合状态、使用痕迹 | 随机瓶身、文字乱码、产品变形 |
| 场景 | 前景/中景/后景、光源入口、道具位置、动线 | 空背景、无生活/品牌功能空间 |
| 光影 | 色温倾向、主光方向、暗部保留、反射路径 | 无来源光、全脸均匀亮、假体积光 |
| 材质 | 皮肤纹理、膏体厚度、玻璃反射、金属边缘 | 糊成一团、过度磨皮、CG高光 |
| 镜头 | 焦段感、景别、机位高度、构图意图 | 花哨构图、看不清产品 |

## 三、资产链路

1. 人物先锁身份：面部识别点、肤色、发型、妆容、体态。
2. 产品先锁结构：瓶型、盖子、标签、颜色、尺寸比例。
3. 场景先锁职能：使用场景、展示场景、证明场景、品牌收束场景。
4. 分镜只允许组合已锁定元素；变化必须来自剧情、动作或镜头，不来自随机换设定。

## 四、质量检查

- 单独看一张图，能否判断产品是什么、人物在做什么、光从哪里来。
- 连续看三张图，人物、产品、场景是否保持一致。
- 删除文案后，画面是否仍能表达卖点或情绪。
- 任何画面出现 CG感、假城市、棚拍无生活痕迹、过度滤镜、无来源光效，直接重写提示词。
