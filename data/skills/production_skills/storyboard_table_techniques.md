# 分镜表通用技法

本文档只服务分镜表阶段。目标是把广告脚本转成可拍、可生成、可审核的镜头表，不改写文案，不新增脚本外创意。

## 一、分镜拆分原则

### 什么时候新起分镜

- 场景 / 地点切换。
- 时间跳变。
- 画面主体切换：人物反应、产品特写、手部操作、环境证据之间切换。
- 景别明显变化：中景转特写、特写转大特写等。
- 关键动作节点：拿起、打开、挤出、滴落、涂抹、等待、观察、收回、展示。
- 产品证据点变化：包装信息、质地状态、肤感变化、使用前后、功能结果。
- 文案 / VO 语义停顿：一句话内出现明显分句、转折、强调点。

### 什么时候不必新起分镜

- 同一画面内的连续小动作，如手指继续旋瓶盖、刷头继续贴肤滑动。
- 同一产品动作链自然推进，且 1 镜能看清。
- 表情、呼吸、视线的小变化，只要不构成新信息点。
- 纯装饰性环境细节，除非它承接转场或证明产品使用场景。

### 粒度

- 1 个独立画面 = 1 镜。
- 1 个连续产品动作链可合成 1 镜，如“拿起瓶身→旋开瓶盖→滴管离开瓶口”。
- 长文案 / 长 VO 按语义停顿拆成连续镜，画面换景别或视角，文案原文不改。
- 每镜只承载 1 个核心信息点，最多附带 1 个辅助状态。

## 二、镜头合并规则

### 定场防冗余

每个新场景最多 1~2 镜完成定场。能用一镜交代“场景 + 主体 + 产品位置”的，不拆成环境空镜、局部细节、人物到达三段。

推荐：
- 中景：使用者站在浴室镜前，产品在台面前景，手伸向瓶身。
- 远景缓推：门店展示区全貌，顾客走近主推产品陈列。

不推荐：
- 先空拍浴室。
- 再拍台面一角。
- 再拍使用者进门。
- 再拍产品。

### 合并信号

- 相邻 2~3 镜只是在同一空间展示不同局部，且没有新卖点。
- 一镜带轻微运镜就能完成“产品亮相 + 使用者动作 + 场景关系”。
- 纯装饰镜头不提供产品信息、动作推进或情绪变化。
- 同一文案下的画面只是轻微变换角度，未产生新证据。

### 不该合并的情况

- 一镜里出现两个以上关键产品证据，如“开瓶 + 滴落 + 上脸 + 吸收结果”。
- 同一镜需要跨地点或跨时间。
- 文案超过可读时长，画面又没有足够动作变化。
- 需要从人物反应切到产品大特写，且两个信息都重要。

## 三、一镜到底使用边界

一镜到底只在收益明确时使用：
- 产品操作连续：开盖、取量、涂抹、展示结果一气呵成。
- 使用者从 A 点移动到 B 点，中途产品始终在手中或画面中。
- 镜头从场景推到产品特写，过程本身提供信息。

要求：
- `运镜` 写清路径，如“缓推至产品特写”“跟拍手部移动至镜前”。
- `画面描述` 写清起幅和落幅。
- 时长可放宽到 12s 内，但不要滥用。
- 如果模型生成容易断裂，拆成 2 镜更稳。

## 四、视觉连续性

### 动作连续

上一镜手指已经扣住瓶盖，下一镜必须从这个状态继续拧开，不能突然换手或收回。

正确：
- 镜 1：右手拇指和食指扣住瓶盖，腕部开始旋转。
- 镜 2：瓶盖被完整拧开，滴管离开瓶口。

错误：
- 镜 1：右手扣住瓶盖。
- 镜 2：左手拿着已经打开的瓶子。

### 产品连续

需要连续的产品状态：
- 瓶身位置。
- 标签朝向。
- 开合状态。
- 取量状态。
- 内容物是否已滴落 / 已涂开 / 已吸收。
- 包装是否仍在台面、手中、前景或背景。

### 空间连续

同场内人物、产品、台面 / 展示区的左右和前后关系稳定。确需换位，画面描述里写出移动过程。

示例：
- “产品瓶在画面右前景”后，下一镜若产品到左侧，必须写“使用者把产品从右侧拿起并移到左手边”。

### 视线连续

使用者看向镜子、标签、屏幕、产品时，下一镜要承接视线目标。

示例：
- “使用者看向镜中脸颊状态”后，可接“镜中脸颊局部特写”或“使用者手指轻触同一侧脸颊”。

### 片段边界连续

相邻片段边界用动作、视线、音效或产品状态承接，避免硬跳。

可用桥梁：
- 动作桥梁：手指扣住瓶盖 → 瓶盖旋开。
- 视线桥梁：看向标签 → 产品标签近景。
- 声音桥梁：瓶盖咔哒声延续到下一镜。
- 状态桥梁：一滴精华落下 → 手背上出现薄薄水感边缘。

## 五、节奏与时长

### 基础参考

| 内容 | 建议时长 |
|---|---|
| 产品 / 手部大特写 | 2-4s |
| 普通使用动作 | 3-6s |
| 复杂连续动作 | 5-8s |
| 人物反应 | 2-4s |
| 场景建立 | 3-5s |
| 长文案承载镜 | 按 4 字/秒估算 |

### 黄金 6 秒规则

无文案镜累计超过 6s 必须出现新信息：新动作、新产品状态、新视角或新反应。没有新信息就压缩或合并。

### 文案时长

文案 / 台词按约 4 字/秒估算，再加：
- 每个逗号、句号、顿号、分号：+0.3s 到 +0.5s。
- 情绪或强调停顿：+0.5s。
- 安全余量：+1s。

片段累计不超过 15s。

## 六、字段填写口径

当前分镜表字段固定为：

`| 序号 | 画面描述 | 时长 | 景别 | 运镜 | 文案/台词 | 音效 |`

### 画面描述

写可见主体、动作、产品交互、状态变化、空间关系。

必须写：
- 谁 / 什么产品在画面中。
- 做了什么动作。
- 产品处于什么状态。
- 画面前中后关系或关键位置。
- 与上一镜的连续状态。

不要写：
- 心理活动。
- 空泛情绪词。
- 人物固有外观，如服装、发型、五官。
- 脚本、视觉手册或资产没有指定的风格化光线。
- 画外字幕、UI 文字、水印。

产品证据写法：
- 开合：瓶盖旋开、按压泵头、粉盒打开。
- 取量：滴管悬停、一滴落下、刷头沾取薄层。
- 质地：透明液滴、膏体边缘、粉体附着、刷毛贴肤。
- 延展：从一点推开成薄层、边缘渐薄。
- 结果：手背水感边缘、唇面光泽、妆效边界、包装回到前景。

### 景别

| 景别 | 用法 |
|---|---|
| 大远景 / 远景 | 场景建立、空间关系 |
| 全景 | 人物与产品 / 场景关系 |
| 中景 | 使用动作、讲解、展示 |
| 近景 | 表情、手部与产品交互 |
| 特写 | 产品、包装、手部、质地 |
| 大特写 | 滴液、粉体、刷头、肤感边界等关键证据 |

景别错开：
- 相邻镜尽量不要连续 3 镜同景别。
- 同一动作拆多镜时，至少换角度或换景别。

### 运镜

无运镜写 `固定`。

| 运镜 | 用法 |
|---|---|
| 缓推 | 靠近产品证据、强调结果 |
| 缓拉 | 从细节释放到场景关系 |
| 跟拍 | 跟随手部、人物、产品移动 |
| 横移 | 展示陈列、台面、多产品关系 |
| 轻摇 | 从人物反应转到产品 |
| 俯拍 | 台面、手部、取量、摆放 |
| 仰拍 | 货架、人物拿起产品、包装气势 |
| 固定 | 产品特写、质地证据、屏幕/台面稳定信息 |

### 文案/台词

- 广告脚本中的文案、VO、屏幕文字、系统播报必须逐字搬运。
- 不翻译、不总结、不改顺序。
- 可标注来源，如 `VO：『...』`、`使用者：『...』`。
- 无内容留空或写 `无`，按当前输出格式保持一致。

### 音效

只写环境音 + 动作音 / 拟音。

允许：
- 瓶盖旋开声。
- 滴液声。
- 刷毛扫过皮肤声。
- 浴室轻微水声。
- 包装放回台面轻响。
- 门店环境人声低频。

禁止：
- BGM。
- 配乐。
- 音乐。
- 旋律。
- 乐器铺底。
- 情绪音乐、氛围音乐。

## 七、资产引用

片段级写 `引用资产名称` 和 `引用资产ID`。

规则：
- 画面可见的人物 / 代言人、产品、道具、场景，若 assets 中已有，必须引用真实 ID。
- 手部、背影、虚焦剪影只要能辨识为已有人物，也要引用人物资产。
- 产品只出现局部、标签、瓶盖、包装边缘，也要引用产品资产。
- 缺少基础资产时不编造名称和 ID，只在画面内容中忠实体现。
- 有匹配衍生状态时用衍生 ID。
- 同一父资产同一片段内不要主 / 衍生同时引用。

## 八、转场规则

- 同场默认硬切。
- 跨场按导演规划处理；未要求过渡就直接硬切。
- 需要过渡时，优先用产品动作、视线、环境音或短空镜承接。
- 叠化 / 淡入淡出只用于时间跨度或段落收束。
- 禁花哨转场，如划屏、旋转、百叶窗等。

## 九、输出前自检

1. 广告脚本顺序是否完整覆盖。
2. 文案 / 台词是否逐字保留。
3. 每个片段是否 <=15s。
4. 长文案是否拆镜。
5. 人物、产品、关键道具是否凭空消失。
6. 产品开合、标签朝向、取量状态是否连续。
7. 是否引用了已有资产真实 ID。
8. 是否擅自新增光线 / 色调 / 配乐。
9. 相邻镜是否有必要的景别或视角变化。
10. 画面描述是否可拍、可生成、无心理空话。
