# 分镜提示词通用技法

提示词生成是格式转换，不是二次创作。分镜表是唯一画面来源；风格手册只提供视觉表达方式，不能覆盖分镜内容。

## 一、适用模式

只支持参考图一致性工作流：
- Seedream / 豆包类：中文自然语言 prompt。
- Nanobanana / Gemini 类：英文 JSON prompt。

不生成纯文生图 prompt。

## 二、忠实性铁律

1. 分镜表「画面描述」里的主体、动作、产品、空间关系、状态变化必须全部进入 prompt。
2. 只改表达形式，不改语义；中文可转英文，但不能改画面内容。
3. 不添加分镜表没有的装饰元素、人物、产品、场景或道具。
4. 光线 / 色调只允许继承分镜表、视觉手册或资产已有状态，不擅自新增。
5. 文案 / 台词、VO、音效不进入图片 prompt。
6. 风格词从属于画面描述，不能让风格词挤掉产品证据。

## 三、首帧原则

分镜图是视频首帧参考。

| 分镜描述类型 | 处理方式 | 示例 |
|---|---|---|
| 静态瞬间 | 按原描述生成 | “产品瓶立在台面前景”直接生成 |
| 连续动作 | 取动作起始的清晰瞬间 | “一滴精华落下”取液滴刚离开滴管 |
| 运镜 | 取起始景别作为首帧构图 | “缓推至产品特写”取缓推开始景别 |
| 淡入 / 黑场 | 生成淡入后的第一个可见画面 | “黑场淡入浴室台面”生成浴室台面 |
| 结果展示 | 保留结果状态 | “涂开后形成薄薄水感边缘”生成涂开后的边缘 |

不要把所有动作都改成“即将发生”。如果分镜写的是“已经滴落”“已经涂开”，首帧就应显示该状态。

## 四、字段映射

| 分镜表字段 | prompt 处理 |
|---|---|
| 画面描述 | 主体内容，完整保留并视觉化 |
| 场景 | 作为环境锚点，使用对应 `@图N` |
| 景别 | 转成构图词 |
| 运镜 | 只用于判断首帧，不写成视频运动 |
| 文案/台词 | 不进入图片 prompt |
| 音效 | 不进入图片 prompt |
| 引用资产ID | 用于生成 `@图N` 参考图绑定 |

逐字段回溯检查：
- 画面主体有没有丢。
- 产品动作有没有丢。
- 产品状态有没有丢。
- 空间关系有没有丢。
- 景别是否匹配。
- 是否引入了分镜表没有的画面内容。

## 五、景别词库

| 输入 | 英文 | 中文 |
|---|---|---|
| 大远景 / 大全景 | extreme wide shot, establishing shot | 大远景构图，环境全貌 |
| 远景 / 全景 | wide shot, full shot | 远景 / 全景构图，主体与环境关系明确 |
| 中景 | medium shot | 中景构图，动作与主体关系清楚 |
| 近景 | medium close-up | 近景构图，手部 / 表情 / 产品交互清楚 |
| 特写 | close-up | 特写构图，产品或局部细节清晰 |
| 大特写 | extreme close-up, macro detail | 大特写，质地和微小动作清晰 |
| 过肩镜 | over the shoulder shot | 过肩构图，前景虚化，目标清晰 |
| 俯拍 | top-down shot | 俯拍构图，台面和手部关系清楚 |
| 低角度 | low angle shot | 低角度构图，产品或人物更突出 |

复合景别按首帧取左侧起始景别，如“远景→中景”取远景。

## 六、Seedream 输出结构

```
@图1 为{资产名称}{资产类型} @图2 为{资产名称}{资产类型} ... ,

【画面】{场景锚点}，{景别构图}，{完整画面描述，资产名称替换为@图N，保留动作、产品交互、空间关系、状态变化}。
【风格】{风格手册提供的必要风格词和画质锁定词}，禁止画外字幕、水印、UI文字。
保持 @图N 的人物、产品、包装、场景与参考图一致。
```

规则：
- `【画面】` 最长，承载分镜表全部视觉信息。
- `【风格】` 最短，只放必要画质和风格约束。
- 不单独生成 `【光影】` 段，除非分镜表 / 视觉手册 / 资产已经明确给出光线状态。
- 参考图绑定靠 `@图N`，不要再写一段英文解释参考图。

## 七、Nanobanana / Gemini 输出结构

```json
{
  "role": "You are a storyboard image prompt writer. Preserve the referenced people, products, props, and environment exactly.",
  "references": [
    { "image": 1, "ref": "@图1", "type": "{assetType}", "name": "{assetName}" }
  ],
  "shot": {
    "scene_and_framing": "{scene anchor + shot size}",
    "subject_and_action": "{complete visual description, using @图N for referenced assets}",
    "style": "{style manual terms + image quality lock}"
  },
  "negative": "subtitles, watermark, UI text, extra people, extra products, wrong logo, unreadable label text"
}
```

规则：
- `subject_and_action` 是主字段，必须完整承载画面描述。
- `style` 不得压过主体内容。
- `negative` 必须包含禁止字幕、水印、UI 文字、额外人物、额外产品、错误 logo、不可读标签文字。

## 八、图像资产标注规则

每条 prompt 必须以图像资产标注开头。

规则：
- 编号按 `associateAssetsIds` 顺序，从 `@图1` 开始。
- 每个引用资产 ID 对应一个标注项。
- 资产名称使用 assets 里的真实 `name`。
- 正文里所有已引用的人物 / 产品 / 道具 / 场景名称，都用对应 `@图N` 替代。
- 同一 `@图N` 可以多次出现。
- 产品类资产要特别保持包装形状、瓶身比例、标签位置、开合状态和使用状态。

类型映射：

| assets type | 标注 |
|---|---|
| role | 人物 |
| tool | 产品/道具 |
| scene | 场景 |
| clip | 片段 |

错误：
```
@图1 为精华瓶产品, 精华瓶放在台面上，标签朝向镜子。
```

正确：
```
@图1 为精华瓶产品, 【画面】@图1 放在台面上，标签区域朝向镜子，瓶盖处于旋开状态。
```

## 九、人物、产品位置与朝向连续性

当前分镜表没有独立朝向 / 空间关系列，必须从「画面描述」推断并保持连续。

### 人物

- 同场同人物的左右位置、前后层次保持稳定。
- 视线目标要延续，如看向镜子、看向标签、看向手背。
- 转身、转头、移步必须来自画面描述，不可凭空改向。
- 镜中反射的人物左右关系相反，但真实人物位置不变。

### 产品

- 标签朝向要连续。
- 瓶盖、泵头、粉盒、刷头等开合状态要连续。
- 产品从台面到手中、从前景到背景，需要动作交代。
- 内容物状态要连续：未取量、已取量、滴落中、已涂开、已吸收。
- 产品不能凭空消失；除非分镜表写明收起、放下、移出画面。

## 十、文字规则

- 画外字幕、水印、UI 文字一律禁止。
- 产品标签如果参考图里已有，只保持“标签区域 / 色块 / 版式”，不要生成新可读文字。
- 分镜表明确要求屏幕或包装出现文字时，按脚本原文处理，但图片 prompt 仍优先描述为画内物件，不生成额外字幕。
- 文案 / 台词 / VO 不作为画外字幕写进图片 prompt。

## 十一、光线与色调边界

允许：
- 视觉手册已经规定的光线状态。
- 场景资产中已经存在的光线状态。
- 分镜表明确要求的产品证据光线，如“参考图已有的反光边缘”。

禁止：
- 自行添加暖色夕阳、逆光、蓝调、强对比、电影感暗光等风格化光线。
- 用光线词替代产品证据。
- 让光线状态与参考图冲突。

如果不确定，少写光线，多写产品动作和状态。

## 十二、完整示例

输入分镜：

| 字段 | 内容 |
|---|---|
| 画面描述 | 使用者右手拧开磨砂精华瓶盖，瓶身稳定立在白瓷台面上，正面标签朝向镜面但不生成可读文字。 |
| 景别 | 特写 |
| 运镜 | 固定轻推 |
| 引用资产ID | [101, 202, 300] |

Seedream 输出：

```
@图1 为使用者人物 @图2 为磨砂精华瓶产品 @图3 为浴室台面场景,

【画面】@图3 中，特写构图，@图1 的右手拇指和食指正在拧开 @图2 的瓶盖，@图2 稳定立在白瓷台面上，正面标签区域朝向镜面但不生成可读文字，瓶身比例、包装形状和标签位置保持与参考图一致。
【风格】真实广告分镜图，画质清晰，产品边缘干净，禁止画外字幕、水印、UI文字。
保持 @图1、@图2、@图3 与参考图一致。
```

## 十三、自检

输出前逐项检查：
1. 画面描述没有遗漏。
2. 所有引用资产都用 `@图N` 绑定。
3. 没有新增人物、产品、道具、场景。
4. 没有把文案 / 台词 / 音效写进图片 prompt。
5. 没有擅自新增光线或色调。
6. 产品包装和使用状态与参考图 / 分镜表一致。
7. 位置、朝向、标签方向、开合状态与上一镜连续。
8. 风格词没有压过产品证据。
